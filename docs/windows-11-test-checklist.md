# Windows 11 실기기 점검 체크리스트

GitHub Actions는 빌드·단위 테스트·배포 패키징을 확인하지만 실제 Windows 11의 SMB, NTFS ACL, UAC 및 다른 PC 접속까지 대신 검증하지는 않습니다.

## 준비

- [ ] Windows 11 x64 PC에서 실행
- [ ] 테스트용 로컬 폴더와 내부 파일 준비
- [ ] 테스트용 로컬 사용자 또는 그룹 준비
- [ ] 현재 폴더의 기존 NTFS 권한을 미리 기록
- [ ] 같은 내부 네트워크의 접속 확인용 PC 준비

실제 자료가 들어 있는 폴더보다 별도의 테스트 폴더를 사용하는 것을 권장합니다.

## 실행과 조회

- [ ] 일반 실행 시 UAC 관리자 권한 요청 표시
- [ ] UAC 허용 후 프로그램 실행
- [ ] 일반 SMB 공유만 목록에 표시
- [ ] `ADMIN$`, `IPC$`, `C$` 등 관리 공유가 표시되지 않음
- [ ] 한글 경로와 공백 포함 경로가 정상 표시
- [ ] 새로 고침 후 외부에서 변경한 공유 상태 반영

## 기준 네트워크 어댑터

- [ ] 기본 게이트웨이가 있는 실제 Ethernet 또는 Wi-Fi 어댑터가 자동 선택됨
- [ ] VMware, Hyper-V, WSL 등의 가상 어댑터가 기본 목록에서 숨겨짐
- [ ] `가상/VPN 어댑터 표시` 선택 시 가상 어댑터가 표시됨
- [ ] 다른 어댑터 선택 시 메인 화면의 이름·IPv4·프로필이 변경됨
- [ ] 프로그램 재실행 시 마지막 선택 어댑터가 복원됨
- [ ] 저장된 어댑터가 사라진 경우 사용 가능한 어댑터가 자동 선택됨
- [ ] 어댑터 다시 검색 시 최신 연결 상태가 반영됨

## 공유 생성

- [ ] 한글 폴더와 한글 공유 이름
- [ ] 공백이 포함된 폴더와 공유 이름
- [ ] 모든 사용자 읽기 전용
- [ ] 특정 로컬 사용자 읽기 및 쓰기
- [ ] `BUILTIN` 로컬 그룹 선택
- [ ] 모든 권한은 직접 선택했을 때만 적용
- [ ] 중복 공유 이름 차단
- [ ] 존재하지 않는 폴더와 UNC 경로 차단
- [ ] SMB와 NTFS 권한이 선택한 단계로 설정됨

## 공유 수정

- [ ] 설명 변경
- [ ] 접근 계정 추가
- [ ] 기존 계정 권한 변경
- [ ] SMB 권한만 제거
- [ ] NTFS 권한 동시 제거 경고와 기본 선택 확인
- [ ] 다른 계정의 NTFS 권한과 상속 상태가 유지됨
- [ ] 기존 Deny 규칙은 표시되지만 수정되지 않음

## 공유 삭제

- [ ] 삭제 확인창의 기본 선택이 `아니요`
- [ ] 공유 설정만 제거됨
- [ ] 실제 폴더가 유지됨
- [ ] 내부 파일이 유지됨
- [ ] NTFS 권한이 자동 제거되지 않음
- [ ] `Ctrl` 또는 `Shift`로 여러 일반 공유 선택
- [ ] 선택한 여러 공유의 일괄 삭제 결과가 정확히 집계됨
- [ ] 일괄 삭제 중 한 항목 실패 시 나머지 항목은 계속 처리됨
- [ ] 시스템·관리 공유를 삭제할 수 없음

## 프린터 공유

- [ ] 이 PC에 설치된 로컬 프린터가 목록에 표시됨
- [ ] 네트워크 연결 프린터는 로컬 공유 관리 목록에서 제외됨
- [ ] 공유하지 않은 프린터에 공유 이름 설정
- [ ] 기존 프린터 공유 이름·설명·위치 변경
- [ ] 중복되거나 잘못된 공유 이름 차단
- [ ] `\\PC이름\프린터공유이름` 경로 복사
- [ ] 다른 PC에서 공유 프린터가 검색되거나 UNC 경로로 연결됨
- [ ] 프린터 공유 해제 후 프린터 장치가 유지됨
- [ ] 프린터 드라이버, 포트와 인쇄 작업이 변경되지 않음

## 네트워크 접속

- [ ] `\\PC이름\공유이름`으로 다른 PC에서 접속
- [ ] 읽기 전용 계정으로 파일 생성·수정이 차단됨
- [ ] 읽기 및 쓰기 계정으로 파일 생성·수정 가능
- [ ] 암호로 보호된 공유 환경에서 올바른 자격 증명 요청
- [ ] 네트워크 프로필과 활성 IPv4 상태 표시
- [ ] SMB 2/3과 TCP 445 수신 상태 표시
- [ ] 파일 및 프린터 공유·네트워크 검색 방화벽 상태 표시
- [ ] Server, Function Discovery, Print Spooler 서비스 상태 표시
- [ ] 실패·경고 항목에 이해 가능한 설명과 해결 팁 표시
- [ ] 관련 설정 버튼으로 네트워크 설정, 서비스, 방화벽, Windows 기능과 프린터 설정 열기
- [ ] 진단 결과가 선택한 어댑터의 프로필·IPv4를 기준으로 표시됨
- [ ] 자동 수정 확인창의 기본 선택이 `아니요`
- [ ] 공용→개인 프로필 변경 전 같은 프로필의 다른 어댑터에도 반영될 수 있음을 안내
- [ ] 공용→개인 변경 후 Windows가 표시하는 실제 프로필 상태를 다시 확인
- [ ] Server, Print Spooler 및 Function Discovery 서비스 시작
- [ ] 자동 서비스 시작 시 서비스 시작 유형은 변경되지 않음
- [ ] 파일 공유·네트워크 검색 방화벽 규칙은 현재 프로필에만 활성화됨
- [ ] 방화벽 변경이 같은 프로필의 다른 어댑터에도 적용될 수 있음을 확인창에서 안내
- [ ] 자동 수정 후 진단 결과가 다시 조회됨
- [ ] SMB 2/3, IP 구성과 암호 보호 공유에는 자동 수정 버튼이 표시되지 않음

## 로그와 배포

- [ ] `%LOCALAPPDATA%\WindowsShareManager\Logs`에 작업 로그 생성
- [ ] 로그에 암호나 폴더 내부 파일 목록이 기록되지 않음
- [ ] .NET 런타임이 없는 Windows 11 x64에서 배포 EXE 실행
- [ ] ZIP의 SHA-256 값이 함께 배포된 `.sha256` 파일과 일치
